## Perfil profissional

Sou desenvolvedor backend com experiência na construção de APIs, serviços e integrações para ambientes corporativos de alta responsabilidade, especialmente no contexto financeiro.

Atuo com Java, Spring Boot, arquitetura de software, microservices e integração entre sistemas. No dia a dia, trabalho transformando demandas de negócio em soluções técnicas bem estruturadas, com foco em clareza, segurança, manutenibilidade e evolução contínua.

Tenho experiência em projetos corporativos que envolvem integrações com alta plataforma, fluxos transacionais, regras de negócio sensíveis, processamento de dados e APIs consumidas por diferentes canais e sistemas internos.

Por se tratarem de soluções proprietárias e confidenciais, os desenhos técnicos, códigos e detalhes de implementação não são publicados aqui. Este perfil destaca minha atuação técnica, repertório de engenharia e projetos públicos relacionados.

## Como trabalho

- Escrevo código pensando em manutenção, leitura e evolução.
- Valorizo contratos de API claros, nomes bem definidos e comportamento previsível.
- Busco entender o problema de negócio antes de escolher a solução técnica.
- Prefiro arquitetura simples, objetiva e preparada para crescer quando necessário.
- Trato segurança, consistência e rastreabilidade como parte do desenho da solução.

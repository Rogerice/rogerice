- Arquitetura de software, design patterns e boas práticas de código
- Microservices, comunicação entre serviços e integrações

## Como penso engenharia

- Código deve ser simples de ler, testar e evoluir.
- Arquitetura boa é aquela que resolve o problema sem criar complexidade desnecessária.
- APIs precisam ter contratos claros, nomes bons e comportamento previsível.
- Qualidade não aparece só no framework escolhido, mas nas decisões pequenas do dia a dia.
